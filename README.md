# C Programming Repository 🚀

This repository contains **C programs ranging from basic to advanced concepts**, designed to help learners and professionals practice and master C programming.  
All programs can be compiled and executed using the **GCC compiler**.

---

## ⚙️ Prerequisites
- Install **GCC compiler**  
    - On Windows: Install [MinGW](http://www.mingw.org/) or use WSL

Check installation:
```bash
gcc --version

▶️ How to Compile & Run
1. Compile a program
bash
gcc filename.c -o myexe

filename.c → Your C source file

-o output → Name of the executable file

2. Run the program
bash
./myexe
